Prototypes de navigation

Trois pistes pour remplacer la barre de liens unique du haut (7 liens à plat). Chaque prototype simule les 7 pages réelles (Semaine, Jour, Soumettre, Règles, Tâches, Sources, Activité brute) avec des données factices, en clair et en sombre (même palette que l'application). Ouvrez-les par double-clic ; le dossier shared\ doit rester à côté. Ajouter ?theme=dark à l'adresse force le thème sombre.

A — Barre latérale

Navigation classiqueCtrl+K

Menu vertical regroupé en sections (Ma semaine · Envoi · Configuration · Avancé), icônes, pastilles de compteur, repliable en icônes, palette de commandes Ctrl K. Tiroir sur mobile.

Pour

  • Le plus familier ; passe à l'échelle si on ajoute des pages
  • Regroupement clair : le quotidien est séparé de la configuration
  • Pastilles visibles en permanence (trous, source en erreur)
  • Le contenu garde toute la hauteur

Contre

  • Prend 250 px de largeur (64 px replié)
  • Plus de code et de CSS à porter dans la mise en page
Ouvrir le prototype A

B — Barre du haut à onglets

Évolution minimaleMenus déroulants

Trois onglets pour le quotidien (Semaine · Jour · Soumettre), deux menus « Configuration ▾ » et « Plus ▾ » pour le reste, fil d'Ariane et actions sous la barre. Barre d'onglets fixe en bas sur mobile avec feuille « Plus ».

Pour

  • Reste proche de l'existant : la migration est la plus simple
  • Toute la largeur reste pour les tableaux
  • La config n'a plus le même poids que la saisie

Contre

  • Pages secondaires cachées derrière un clic
  • Peu d'espace pour de nouvelles entrées
  • Menus déroulants à soigner au clavier
Ouvrir le prototype B

C — Rail + panneau contextuel

Centré sur la semaineParcours guidé

Rail d'icônes (Temps · Envoi · Config · Avancé) et panneau qui change selon la section : jours de la semaine avec heures, liste de vérification avant envoi, pages de config. En-tête avec parcours « Saisir → Vérifier → Soumettre » et progression en heures.

Pour

  • Raconte le vrai flux de travail (saisir, vérifier, soumettre)
  • Progression et trous toujours visibles
  • Le rail ne mange que 60 px ; le panneau se masque (Ctrl B)

Contre

  • Le plus ambitieux : état partagé et panneaux par section
  • Moins évident au premier regard
  • Les données du panneau doivent venir d'un service
Ouvrir le prototype C

C+ — Soumission jour par jour Nouveau

Extension du prototype C : une bande de jours (Non saisi · Brouillon · Prêt · Envoyé · Modifié depuis l'envoi · Écart) et, sous elle, une simulation par jour avant tout envoi, avec garde-fous anti-doublon (empreinte, verrou, bouton désactivé « Rien de nouveau à envoyer », confirmation seulement pour le risqué, annuler / rejouer, journal par jour). Les étiquettes Existe, Existe (semaine) et À construire distinguent le réel du proposé.

Ouvrir C+ (page Soumettre)

Scénarios (aussi dans la carte « Scénarios de démonstration », ou via ?scenario=…) :

  • neuf : rien n'est encore envoyé ; jours prêts
  • inchange : tout est déjà dans Forecast ; envoi désactivé
  • modifie : brouillon modifié depuis l'envoi ; mise à jour optionnelle
  • conflit : Forecast modifié ailleurs ; résolution à choisir
  • partielle : envoi interrompu ; cellules non tentées à rejouer
  • double : double clic / deuxième envoi ; aucune écriture en double

Déjà dans l'application

Sélection des jours à envoyer (aujourd'hui par défaut), simulation (DryRun), préflight FillGuard, verrou du ForecastRunner, idempotence « déjà dans Forecast », conflit jamais écrasé, reprise après interruption, « Ne pas envoyer » par semaine et tâche, cellules verrouillées / approuvées.

À construire

Statut, empreinte et horodatage par jour (aujourd'hui : semaine seulement), détection « modifié depuis l'envoi », mise à jour d'une valeur existante, suppression dans Forecast, résolutions de conflit, journal d'envoi, annulation, bouton « Soumettre les jours prêts », bande de jours.

Recommandation : A, avec l'en-tête de semaine de C

La barre latérale (A) règle d'emblée les vrais défauts actuels : 7 liens de même poids, aucun regroupement, pas de pastilles, rien pour le mobile. Elle coûte peu en plus de la mise en page existante. On y ajoute ensuite, à moindre risque, le bandeau « Saisir → Vérifier → Soumettre » de C sur les pages Temps et Envoi. B est le bon choix si on veut un changement minimal.

Raccourcis communs

  • Alt+1…7 : aller à la page (dans l'ordre Semaine, Jour, Soumettre, Règles, Tâches, Sources, Activité brute)
  • [ / ] : semaine précédente / suivante · Alt+T : thème clair/sombre
  • A : Ctrl+K ou / palette, Ctrl+B replier · B : ↓ ↑ Échap dans les menus · C : Ctrl+B masque le panneau
